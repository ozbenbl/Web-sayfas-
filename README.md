## 🎨 Tasarım & Özellikler

- **Koyu Pembe Lüks Estetik:** Derin obsidian arkaplan (`#0c0710`), neon koyu pembe vurgular (`#ff2d75`), cam efekti (glassmorphism) ve yumuşak ambiyans ışımaları.
- **Tam Duyarlı (Responsive):** Mobil telefonlar, tabletler ve geniş ekranlı masaüstü monitörlerle %100 uyumlu arayüz.
- **Akademik & Staj Odaklı Bölümler:**
  - **Hero Alanı:** Durum rozeti, dikkat çekici başlık, hızlı bağlantılar ve 3D teknoloji vitrini.
  - **Hakkımda:** Veri analitiği ve yazılım vizyonunu anlatan akademik biyografi ve kişisel özet kartı.
  - **Eğitim:** Anadolu Üniversitesi'ndeki iki farklı programın detayları ve kazanımları.
  - **Yetenekler:** Büyük Veri, Web & Yazılım ve Araçlar olmak üzere 3 kategoride sınıflandırılmış beceri kartları.
  - **Staj & Projeler Vitrini:** Staj sürecinde geliştirilen Büyük Veri Analiz & KPI Takip Paneli projesi ve teknik detayları.
  - **Etkileşimli İletişim:** 1 tıkla e-posta kopyalama butonu, bildirim (toast) sistemi ve doğrudan mailto entegrasyonlu mesaj formu.
  - **Mobil Hamburger Menü:** Küçük ekranlarda akıcı açılır kapanır menü.

## 🚀 Projeyi Yerel Ortamda Çalıştırma (VS Code)

1. Projeyi Visual Studio Code ile açın.
2. VS Code eklentilerinden **Live Server** eklentisini yükleyin.
3. `index.html` dosyasına sağ tıklayıp **"Open with Live Server"** seçeneğini seçin veya doğrudan `index.html` dosyasını tarayıcınızda çift tıklayarak açın.

## 🌐 GitHub ve GitHub Pages'e Yükleme Rehberi

Siteyi canlı yayına alıp hocanıza göndermek için şu adımları takip edebilirsiniz:

1. **Git Başlatma ve Commit:**
   ```bash
   git init
   git add .
   git commit -m "feat: Özben Bülbül koyu pembe portfolyo ve staj vitrini"
   ```

2. **GitHub Deposu Oluşturma:**
   - [GitHub](https://github.com/new) adresinden yeni bir genel (Public) repository açın (Örn: `portfolio` veya `ozben-portfolyo`).
   - Terminalde deponuzu bağlayıp push yapın:
   ```bash
   git branch -M main
   git remote add origin https://github.com/ozbenbl/DEPO_ADINIZ.git
   git push -u origin main
   ```

3. **GitHub Pages ile Canlıya Alma:**
   - GitHub deponuzun **Settings (Ayarlar)** sekmesine gidin.
   - Sol menüden **Pages** seçeneğine tıklayın.
   - **Branch** kısmından `main` ve `/ (root)` seçip **Save** butonuna basın.
   - 1-2 dakika içinde `https://ozbenbl.github.io/DEPO_ADINIZ/` şeklinde canlı linkiniz hazır olacaktır. Bu linki doğrudan hocanıza iletebilirsiniz!
